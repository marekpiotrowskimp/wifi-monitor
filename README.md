# WiFi Monitor

An **iOS + watchOS** app for monitoring your Wi-Fi connection: signal strength, network details, home-screen widgets and Apple Watch complications.

## Features

- Current network info (SSID, BSSID, signal strength, security)
- iOS widget and watch complications
- Data shared between the app, widgets and the watch through App Groups
- SwiftUI and WidgetKit; the project is generated by [XcodeGen](https://github.com/yonaskolb/XcodeGen) from `project.yml`

## Build

```sh
xcodegen
open WifiMonitor.xcodeproj
```

Reading the SSID on iOS requires the *Access WiFi Information* entitlement and location permission.
`generate_icons.swift` renders the app icons. Development notes (in Polish): [SESSION_NOTES.md](SESSION_NOTES.md).
